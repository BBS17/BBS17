## 👋 A little about me

I’m Bricio, a computer science graduate and full-stack developer who enjoys making complicated workflows feel simple. I care about the details people notice: a friendly interface, a fast interaction, a useful error message, and software that keeps working after the demo.

I’m happiest when I can move between product ideas, frontend polish, backend architecture, and the systems that get everything shipped.

## 🚀 What I’m building

### Event Collaboration Platform

An event-planning workspace connecting clients, planners, managers, and workers in one place.

`React` `FastAPI` `PostgreSQL` `Docker` `GitHub Actions`

It brings together event forms, setup sheets, schedules, document sharing, role-based views, staffing changes, and communication—so teams spend less time hunting for information.
