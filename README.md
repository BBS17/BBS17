## What I’m building now

### Event Collaboration Platform

A production-minded platform for coordinating events between clients, event planners, managers, and workers.

- React frontend with reusable component patterns
- FastAPI/Python backend with role-aware workflows
- PostgreSQL data model and document uploads
- Separate client, worker, planner, and admin experiences
- Docker-based local development and CI checks
- Vercel frontend and cloud-hosted API deployment

The goal is simple: make event details, schedules, setup documents, staffing changes, and communication easier to manage in one place.
